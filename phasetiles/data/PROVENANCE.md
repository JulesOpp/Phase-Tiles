# rcsr2d.cgd
Source: Reticular Chemistry Structure Resource (RCSR), http://rcsr.net,
file RCSRnets-2019-06-01.cgd (O'Keeffe, Peskov, Ramsden, Yaghi,
Acc. Chem. Res. 41, 1782 (2008)).
Changes: kept only entries whose GROUP is one of the 17 plane groups
and that have a NAME (199 nets); 3D entries removed; text otherwise
unchanged.  Regenerate with tools/extract_rcsr2d.py.
Users can point Preferences > RCSR file at their own full copy; only
its 2D entries are read.
